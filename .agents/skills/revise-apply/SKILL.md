# Revise Apply Skill v2

## Purpose

Correct Apply result after review findings.

## Revision Process

Classify:

- implementation defect
- missing verification
- evidence problem
- scope violation

Apply minimum fix.

Then:

- rerun affected verification
- update evidence
- prepare new review

## Forbidden

Do not:

- hide failing tests
- remove evidence
- modify review verdict
- expand scope without authorization

## Output

Updated implementation evidence.
