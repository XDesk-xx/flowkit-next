# Revise Explore Skill v2

## Purpose

Revise Explore according to Review findings.

## Revision Process

1. Read finding.
2. Classify:

- missing evidence
- incorrect assumption
- incomplete risk scan
- invalid boundary
- authority issue

3. Apply minimum correction.

Update only:

- facts
- risks
- proof
- evidence
- limitations

## Forbidden

Do not:

- remove failed evidence
- rewrite facts to obtain PASS
- expand scope to avoid a finding
- start implementation

## Output

Revised Explore Result.
