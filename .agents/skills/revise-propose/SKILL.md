# Revise Propose Skill v2

## Purpose

Update OpenSpec Proposal after review findings.

## Process

Classify:

- missing requirement
- unclear acceptance
- scope mismatch
- design ambiguity
- verification gap

Apply minimal correction.

## Rules

Keep:

- Explore boundary
- OpenSpec authority
- measurable acceptance

Do not:

- add new subsystem
- bypass blocker
- redesign the project

## Output

Updated Proposal ready for re-review.
